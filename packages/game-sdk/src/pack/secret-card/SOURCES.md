# Material sources

**Tablecloth** supplies the crossing weave layers; **Diagonal stripes** supplies the printed diagonal repeat. Both are taken from the gallery’s real CSS and rescaled/recoloured. The existing flip plate, back/face layout, live labels, and secret-card subpath remain intact.

New work for gaps: Thin printing, paper fibre density, and fixed edge lighting. No opacity, filter, or shadow is added to the turning plate, preserving its existing 3D context.

All visible pigment comes from `packages/client/src/styles/tokens.css`. Pattern dimensions, alpha, and stop positions are adapted to the existing components. No animation, class, export, prop, or game rule is changed. Contrast removes the decorative paint.
