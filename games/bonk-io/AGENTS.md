# Bonk.io

Read README.md as the spec. Server physics is deterministic, fixed-step and pure; event time and state rng are the only clocks/randomness. Resolve simultaneous contacts and falls without seat-order scoring advantages. All arena information is public. Stable slot numbers survive departures. A temporary disconnect releases controls but preserves the ball; permanent departures cannot return. Every phase exits without waiting for phones.

Use only the real SDK for server imports and SDK/React in clients. Original numbered SVG art, PartyBox tokens and reduced motion; never colour alone. Stage phones and spectators see the arena. Hold controls must release on cancel, lost capture, blur, pause and round changes. Root runs only this game's tests; no whole-suite run or browser launch by subagents. Research and exact evidence live in jobs/P23-bonk-io.
