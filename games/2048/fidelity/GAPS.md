# Original fidelity review

Preliminary review, 2026-10-12. The essential original surface is the player's private phone board. This file distinguishes observed differences from changes that are implemented but still need fresh capture evidence.

The reference is the [original classic release at `478b6ec`](https://github.com/gabrielecirulli/2048/tree/478b6ec346e3787f589e4af751378d06ded4cbbc). The public original URL redirected to the newer play2048.co tutorial during capture, so the classic release was run in a temporary reference checkout. Only comparison screenshots and capture metadata are included here; original source and font assets are not included.

`original-states.json` records ordinary keyboard play in a fresh profile at 390 × 844: start, then twelve arrow keys producing eleven accepted moves and score 24. Both captures settle for 700 ms. The port's matching boards and scores are visible in `ours-start.png`, `ours-midgame.png`, and `side-by-side.png`. The original board is 280 × 280 at both moments; the captured port board has the same scale. The host header and original scrollbar explain different absolute screen offsets.

Remaining gaps, ranked by effect on the player:

1. **Private HUD geometry — recapture required.** The current comparison was made before the final HUD sizing repair. It shows taller/wider score boxes and a full-width goal sentence where the original puts the goal at left and an action at right. Current source uses the original 55%/42% arrangement, 60 × 55 score boxes, and the race clock in the former action slot. A fresh pair must establish the resulting title, HUD, wrapping, and board placement. The original mobile geometry comes from its [stylesheet](https://raw.githubusercontent.com/gabrielecirulli/2048/478b6ec346e3787f589e4af751378d06ded4cbbc/style/main.css).

2. **Terminal payoff — implementation needs evidence.** The original keeps the final board under its message, with a 1,200 ms delay and 800 ms fade. The port preserves the private board for 3,000 ms after either a target win or the final blocked board: the original delay/fade plus a fully visible second before global standings. A blocked player's board also remains while rivals continue racing. An authoritative public deadline freezes and shifts with pause/resume, including after a phone reload. Target and blocked reveals add these 3,000 ms before the complete ranking reading window. Fresh terminal captures and the updated server checks are still required; settled start/midgame images cannot establish this behavior. Timing is documented in the [original stylesheet](https://raw.githubusercontent.com/gabrielecirulli/2048/478b6ec346e3787f589e4af751378d06ded4cbbc/style/main.css).

3. **Motion and score feedback — source aligned, transient comparison pending.** Current source restores 100 ms tile travel, 200 ms spawn/merge effects delayed 100 ms, and the 600 ms rising score addition. The original renders previous positions and both merging source tiles; the port derives movement from accepted board changes and the player's accepted direction. Settled screenshots prove neither interpolation nor score-rise timing. Capture a merge and its score increment during motion before claiming a match. Primary references: [CSS](https://raw.githubusercontent.com/gabrielecirulli/2048/478b6ec346e3787f589e4af751378d06ded4cbbc/style/main.css), [actuator](https://raw.githubusercontent.com/gabrielecirulli/2048/478b6ec346e3787f589e4af751378d06ded4cbbc/js/html_actuator.js).

4. **Font metrics — known remaining difference.** Original captures use Clear Sans; the port uses system Arial at the original sizes and weight. Arial is an explicit fallback in the [original font stack](https://raw.githubusercontent.com/gabrielecirulli/2048/478b6ec346e3787f589e4af751378d06ded4cbbc/style/main.css), but its glyph widths and shapes still differ visibly. The repository prohibits ripped font assets. This is a documented limitation, not a claim of pixel-identical typography.

5. **Shared TV board shape — source repaired, capture pending.** Live TV maps now use square boards with proportional gaps, corners, and number sizes. Earlier rectangular maps distorted the original puzzle. Fresh eight-player play evidence must show the square maps alongside sofa-readable score and best-tile summaries. Final standings intentionally summarize every rank/name/score/best without repeating all board tiles; the private phone remains the original play surface.

Allowed adaptations are the PartyBox palette, host shell, fair shared spawn sequence, race clock, rank/identity displays, touch direction buttons, pause/reconnect plumbing, and shared final standings. Value-dependent filled tiles, square geometry, score-record BEST, and original input feel remain essential. The private controller now accepts arrows/WASD/HJKL, ignores modifier chords, and uses the original dominant-axis swipe threshold above 10 px. See the [original input manager](https://raw.githubusercontent.com/gabrielecirulli/2048/478b6ec346e3787f589e4af751378d06ded4cbbc/js/keyboard_input_manager.js).

New Game, R restart, Try again, and Keep going are omitted during the synchronized race: independent resets or continuation would invalidate the shared race. Global ranking after the original terminal payoff is the party result flow. These differences do not justify changing the private board's scale, HUD semantics, tile shape, or motion.

The comparison currently demonstrates matching settled board contents, scores, and mobile board scale. It does not yet demonstrate final HUD geometry, transient motion, terminal overlays, or the repaired TV maps. This preliminary review therefore does not mark the fidelity gate complete.
