# P18 assumptions and limitations

- The owner's explicit REA queue workflow takes precedence over the unrelated
  core-team board workflow in C:/dev/team. The run identity is r17-local.
- Colour Gate recreates the colour-match timing mechanic in original PartyBox art.
  The source game's product name appears only in research attribution.
- The original public homepage provides mobile downloads rather than a playable
  JavaScript client. The old Poki source URL returned 404. A surviving host embeds
  a differently titled Inlogic game; its client was not treated as the original.
- The research agent did not start a browser or complete interactive original play.
  The global one-browser budget was preserved for port captures and interaction.
  Original timings and sounds are therefore unmeasured, not claimed as observed.
- Published advice to hover at roughly two taps a second informs the intended feel.
  Exact gravity, bounce impulse, collision thickness and rotation speeds must be
  independently tuned and documented in the port; these are not copied constants.
- Public sources describe both the original release and its rebuilt successor.
  Current store descriptions corroborate the premise, not unchanged original levels.
- Simultaneous lanes, a common seeded course, bounded runs, automatic colour changes
  and distance ranking are living-room adaptations. The final game README is the
  authority for actual settings, timings, scoring and collision behavior.
- Taps represent discrete bounce actions. Touch pressure and holding the surface
  are not assumed to create extra control inputs.
- Every colour must have a distinct redundant symbol/label. Pass, crash and player
  identity must remain understandable without colour discrimination or sound.

Append measured verification limitations here if a check cannot be completed;
do not present a missing run, render or CI result as a pass.
