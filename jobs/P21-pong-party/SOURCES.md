# Sources and assets

Mechanics research only:

- https://niko-game.itch.io/ppong — author's live game listing.
- https://www.atariage.com/2600/manuals_old/warlords.html — original Atari instructions preserved as text.
- https://www.i-volve.net/gd/mind-fragments/octopong — original octagonal game design notes.
- https://github.com/lguibr/pongo — developer rules and server description.
- https://github.com/lguibr/pongo-client — public client inspected for controls and round flow.
- https://github.com/Gr33nOps/pong — developer rules and control description.

All shipped art is original inline SVG and CSS. Colours, typography, and sound cues use the published PartyBox SDK and design tokens. No downloaded art, audio, fonts, logos, or original source code are incorporated.
