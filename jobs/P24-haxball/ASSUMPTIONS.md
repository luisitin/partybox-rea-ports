# P24 assumptions and research limits

- The owner authorizes the public REA workflow, this clone, job/P24-haxball, existing credentials,
  PR creation and main CLAIMS.md coordination. Team-v2 local worktree/queue rules do not replace it.
- Main's Names amendment requires Haxball / haxball. The monorepo inventory at 475a8f78
  (origin/main 1c813f96) has 111 manifests including the template, 110 actual games, and no
  equivalent freely moving two-team football. Shell Hockey has fixed paddles and exactly two
  players; Ball Volley is a one-team relay. P24 remains a separate port.
- Official documentation and independent firsthand accounts establish controls, radial kicks,
  circle physics and goal/team rules. Public client inspection is transient research only;
  no vendor source or assets are copied or retained in this repository.
- Python's official /play request returned 403; PowerShell's public request succeeded. The
  computer-use surface inventory contained no enabled apps/browsers, so no live original match
  was played. Accessible vendor documentation/client and independent sources are fallbacks.
- Two 90-second halves, eight-second halftime, two-second goal reset within the running half
  clock, automatic numbered teams, a helper for odd rosters and tuned physics/cooldown values
  are explicit PartyBox choices or binding job requirements, not claims about original constants.
- The public snapshot exposes SDK primitives rather than a full LAN host. SSR, seeded bots and
  mounted controls cannot substitute for a human network game or an eight-stranger playtest.
- No new dependency is needed. The install was completed once before P03; reuse it.
- Test only games/haxball with one worker. Root alone runs at most one headless browser and
  closes it in finally; no whole-suite browser run.
- gen-registry and verify scripts and docs/ADDING_A_GAME.md are absent from this public snapshot;
  use its typecheck, format and scoped game tests plus the real SDK contract wrapper.
- Goal and kick feedback uses the shell's semantic `cheer` and `thud` cues; no original audio
  is retained. Mounted checks measure cue requests, not speaker acoustics or subjective feel.
- The odd-roster helper uses the normal strategy and 200 ms decision cadence. It does not draw
  the external normal bot's 4% kick-miss sample; competitive human/helper parity is unmeasured.

The bot bank clear uses actual contact geometry and public body positions. It does not guarantee
against own goals; those remain valid game behavior. Goals/half rotate blocked-lane styles so an
identity does not retain the same preferred angle after every reset. The retained 12–12 known-seed
trace is a route-variation diagnostic, not a competitive parity or mixed-skill win-rate measurement.
