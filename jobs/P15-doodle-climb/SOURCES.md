# Sources and asset provenance

Inspected 2026-10-11. Mechanics only; no source code, image, font or audio from these sources is included in the game.

| Source                                                                                                       | Evidence and scope                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Lima Sky's official App Store listing](https://apps.apple.com/us/app/doodle-jump-insanely-good/id456355158) | Developer's own description of controls, platform/boost variants and other-player height markers.                                                       |
| [Macworld, Lex Friedman, 2009-06-02](https://www.macworld.com/article/198325/doodlejump.html)                | Independent firsthand iPhone account: height goal, falling death, platforms, springs and margin records.                                                |
| [Pocket Gamer, Keith Andrew, 2010-03-04](https://www.pocketgamer.com/doodle-jump/review-8982/)               | Independent firsthand Java account: auto-bounce, steering, upward-only progression and randomized layouts. Native version differences are acknowledged. |
| [The en, Windows Phone review, 2011-06-04](https://the-en.com/2011/06/04/wp7-game-review-doodle-jump/amp/)   | Firsthand evidence of opposite-edge wrapping.                                                                                                           |
| [Nintendo Life, Lee Meyer, 2013-11-21](https://www.nintendolife.com/reviews/3ds/doodle_jump_adventures)      | Firsthand comparison explicitly distinguishes the mobile wrap rule from the 3DS border.                                                                 |
| [Pocket Gamer, Chris Schilling, 2011-09-12](https://www.pocketgamer.com/doodle-jump/review-1624/)            | Firsthand iPad account of bounce sound and record markers.                                                                                              |
| [Windows Central, Paul Acevedo](https://www.windowscentral.com/doodle-jump-review)                           | Firsthand Windows Phone control/audio account; native music claim applies to that version only.                                                         |
| [takosenpai2687 public JavaScript replica](https://github.com/takosenpai2687/doodle-jump)                    | Read config, character, platform and main-loop files. Implementation comparison only; exact values are not attributed to the original.                  |

All Doodle Climb game artwork is original inline vector geometry/CSS. Runtime sounds come from existing PartyBox SDK cues. No new external assets or dependencies are needed; there is no CC0 attribution to add.
