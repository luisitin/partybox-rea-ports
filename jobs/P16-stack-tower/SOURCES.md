Native original play and exact-tolerance measurement were unavailable in this research environment. Numeric thresholds found on unrelated browser variants were deliberately not treated as original facts.

## Assets

Skyline Stack uses original React/SVG/CSS geometry and the repository's PartyBox tokens and UI primitives. No third-party sprites, fonts, logos, recordings, music, or trademarked art are permitted. If the implementation later introduces an external asset, record its exact URL, author, licence, and file path here before committing it. The game title is Skyline Stack; the source title is used only for attribution.
